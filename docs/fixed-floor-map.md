# 固定フロアマップ

店内マップの物理レイヤーは`web/fixed-floor.json`を使用する。このファイルは保存版`Numbered map 1.4 ex.Is-ID`のJSONをそのまま同梱したものであり、310台の座標・角度・台番号・島構成・内部Is-IDと1.4の外壁線を変更しない。

`web/fixed-floor.js`がこのレイヤーの各台番号に、選択期間の既存APIの機種名を結び付ける。期間選択、台番号／機種マップの切替、台選択、履歴、検索、変更台の強調は`web/map.js`の既存の動作を引き継ぐ。記録のない台は未掲載、1〜310に含まれない記録は位置を作らず注記する。公開図や旧`physical_positions`の利用者登録座標は、この固定マップに上書きしない。

固定図のviewBoxは`0 0 1060 665`。1.1.1ではユーザーの追加指示により、全310台の四角を一律1.25倍（幅・高さ`10.75`）にする。既存の50pxのHTMLタイルは表示倍率`.215`で流用する。角度・台番号・内部Is-ID・島構成と切れ目は変えない。

一律拡大時に重なった台だけ、所属する島の中心（正本の台中心座標の平均）から外向きに表示位置を離す。別ファイル`web/fixed-floor-display.json`に固定保存し、正本JSON・SVG・PNGは変更しない。対象と変位量は200番（2.1）、223・232番（2.75）、224・231番（0.6）、単位はSVGの座標単位。円弧を推定し直す処理や、島全体の移動・再配置は行わない。全期間、台番号／機種表示で同じ表示調整を使用する。

黄色の変更マークは直径`6.4px × .215`で、従来の`4px × .172`の正確に2倍。選択・フォーカスの枠は四角の内側に収め、状態変更で隣台や外壁にはみ出さない。

配色は機種名のハッシュで色相を決め、同じ明度65%のHSL色を使う。NFKC正規化後の機種名に「ジャグラー」が含まれる系統は彩度90%、その他は18%。既存の背景・枠・番号・機種名・選択枠・変更マークのデザインを流用する。外壁はUI共通の`var(--green)`。

拡大縮小はSVGのviewBoxのみを変更する。100〜800%、倍率スライダー、＋／−、Ctrl＋ホイール、背景ドラッグ、全体表示、選択台への500%以上のズームを提供する。カメラは期間・表示切替でも保持する。機種名は全体表示では小さくなるため、拡大・ツールチップ・選択台の履歴で読む。

ズーム・移動の更新はrequestAnimationFrameで集約し、同一描画フレーム内のイベントは一度だけ反映する。画面座標変換はドラッグ開始時またはホイール操作の開始時だけ取得する。台位置・外壁文字列・台番号索引・操作部品をキャッシュし、表示範囲外の台は描画を省略する。DOMの310台は保持し、カメラを戻せば再表示する。期間再描画時は古いイベントと予約描画を解除する。

## 検証

- `node tests/test_floor_plan.cjs`：正本の310座標・台番号・32内部Is-ID、全310台の一律寸法・5台の外向き表示調整、回転四角の全組合せの非重複（0.1単位の余裕込み）、外壁との非交差・線幅を考慮した間隔、91期間での配置不変、変更マーク2倍、HTMLエスケープ、ズーム・描画集約・画面外省略・ドラッグ座標・再描画時の解除。
- `runtime/python.exe -m unittest discover -s tests -v`：API、静的マップ配信、CSV・データ保存・スクレイピングの回帰テスト。

Windowsの実アプリ1.1.1でも、一律拡大と外向き調整をした232番台の選択・500%表示、42番台の黄色い変更マーク、500%→750%の拡大、750%でのドラッグ、期間切替時の倍率・選択・カメラ位置の保持、台番号／機種マップ切替、500%への縮小、100%の全体表示への復帰を確認した。ドラッグ中に文字が選択される実画面上の問題を見つけ、`user-select: none`とドラッグ開始時の既定動作抑止で修正し、再操作で文字選択が起きないことも確認した。全体表示で310台を再表示した状態でアプリを残した。

固定図は各時期の機種割当を比較する共通の物理レイヤーであり、過去の壁・島形状まで確認できたと解釈しない。元の機種履歴・出典・欠落区間は変更しない。
