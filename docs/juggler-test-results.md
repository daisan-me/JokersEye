## 見つかった問題と修正

- 空白や配列・オブジェクト等が0などへ暗黙変換されていた → 数値型と10進表記を検証。
- 疎な設定表・事前重みからNaNや空の結果が返っていた → 全6要素の存在・設定順・理論確率を検証。
- 巨大な共通対数尤度への加算で小さな事前重みの差が失われていた → 対数尤度比と最適な設定への再基準化。
- 極小のボーナス確率で「その他確率」が1に丸まっていた → `log1p`で確率比を保持。
- 逆算途中のオーバーフローがNaNとして流出する可能性 → 中間演算・出力・精度の検証。アンダーフローも拒否。
- 正常な0回／上限付近の丸め誤差でエラーになる場合 → 補償和と、浮動小数点の誤差範囲だけに限った境界補正。
- 不正／空の機種IDや欠けた機種一覧が通る場合 → 一覧とIDの検証。

## 再実行

アプリのソースルートでNode.js 22以降を使用する。比較用Pythonは同梱の`runtime/python.exe`。

```powershell
node --test --experimental-test-coverage --test-coverage-include="**/juggler-math.js" tests/test_juggler_math.cjs
node tests/test_juggler_preparation.cjs
.\runtime\python.exe -m unittest discover -s tests -p 'test_*.py' -v
```

対象ファイル: `tests/test_juggler_math.cjs`、`tests/juggler_oracle.py`。ネット接続・提供サイトへのスクレイピングは不要。

設定推測の割合は、BB/RB多項モデル・指定した事前重み・メーカーの丸められた公表確率に条件づけた結果であり、実機の真の設定や将来の勝率を保証しない。ぶどう逆算もゲーム数・差枚・獲得条件の定義が一致することが必要で、見込み値を使う場合は近似値になる。
